# CO2 Total-Flooding System Design (NFPA 12) — Implementation Plan

Same concept as the sprinkler module: per-floor architectural DXF/DWG → room detection → select protected
enclosures + questionnaire → NFPA 12 calculation → per-floor shop drawings (DXF/DWG) + schematic/details + calculation
sheet + HTML report. Opus plans/tests/reviews; Sonnet executes.

Contract: `src/renderer/src/engine/fireProtection/co2/co2Types.ts` (do not change field names; additions OK).
Acceptance tests (must pass unchanged):
- `src/renderer/src/engine/__tests__/co2TotalFlooding.test.ts` (C1 engine)
- `src/renderer/src/engine/__tests__/co2DrawingsAndReport.test.ts` (C2 drawings + report)
Run: `npx tsx <file>`. Oracle: scratchpad `co2oracle.py` (CoolProp HEM).

Every NFPA 12 value is cited as "NFPA 12-2022 Ch. 4/5" (clause numbering to be verified against the adopted edition —
use `CODE_NOTE`). Reports and drawings must state: *preliminary NFPA 12 design — the final flow calculation, nozzle
drilling and cylinder quantity are by the manufacturer's listed calculation method*.

### Quantity per enclosure (all lb, ft³)
A = |polygon area| m²; grossV = A·H·FT3; V = max(grossV − deductionM3·FT3, 0).
- Surface: C = max(34, mdc(material)); (f, min) = surfaceFloodingFactor(V); MCF = materialConversionFactor(C);
  openingRate = 1·MCF lb/ft²; tDischarge = 1 min.
- Deep-seated: (C, f, min) = deepSeatedBasis; MCF = 1; openingRate = 2 lb/ft²; tDischarge = 7 min.
- basic = max(V/f, min); openingsLb = openingsM2·FT2·openingRate; ventilationLb = ventilationM3min·FT3·tDischarge / f · MCF.
- T_F = 1.8·°C + 32; pct = T_F > 200 ? (T_F − 200)/5 : T_F < 0 ? −T_F : 0.
- total = (basic·MCF + openingsLb + ventilationLb)·(1 + pct/100).
- Surface: rate = total / 1; soak 0. Deep: thirtyPctLb = V·ln(1/0.7)/9; rate = max(total/7, thirtyPctLb/2); soak 20.
  dischargeTime = total / rate. (Surface: thirtyPctLb = 0.)
- Vent (Annex A, informative, metric form): ventAreaMm2 = 239·(rate/LB_PER_KG)/√(strengthPsf·KPA_PER_PSF); in² = /645.16.
- High-pressure cylinders = ceil(total / cylinderLb) (LP: 0).

### Nozzles
bbox of polygon; nx = max(1, ceil(W/6000)), ny = max(1, ceil(H/6000)); candidate (minX + (i+½)W/nx, minY + (j+½)H/ny);
keep inside polygon; none → centroid. Sort by y then x; tags `N-<floor>-<enc>-NN` (2 digits). q = rate / n.

### Network per enclosure (k = index of the enclosure on the floor, storage (xb, yb))
- xs/ys = sorted distinct nozzle x / y. xh = x in xs nearest xb (tie → smaller); yr = y in ys nearest yb (tie → smaller).
- Header nodes `H-<enc>-<r>` at (xh, ys[r]). A nozzle at (xh, ys[r]) uses that header node as its node; others use their tag.
- main: kind 'main', B → H-<enc>-<rr> (rr = index of yr), points [(xb, yb+400k), (xh, yb+400k), (xh, yr)] with
  consecutive duplicates removed. Fittings: (points − 2) elbows × 30 D + (floor has > 1 enclosure ? selector valve 100 D : 0).
- header: from rr up to each higher row and down to each lower row, segment by segment (H-r → H-r±1), 'header', tee run 20 D.
- branches: per row, nozzles with x > xh ascending and x < xh descending, chained from the header node; first segment
  tee branch 60 D, later ones tee run 20 D.
- D in fittings = ID (in) / 12 ft. Segment flow = downstream nozzles × q. Pipe ids `<floor>-<enc>-M`, `-H<n>`, `-B<n>`.

### Y/Z hydraulics (NFPA 12 Annex)
Q² = 3647·D^5.25·(Y2 − Y1) / (L + 8.08·D^1.25·(Z2 − Z1)), L = length ft + fittings ft, D = ID in.
Traverse from B (P0). Per segment: Y1, Z1 at P1; iterate Y2 = Y1 + (L + 8.08 D^1.25 (Z2 − Z1))·Q²/(3647 D^5.25),
P2 = pressureAtY(Y2), Z2 = Z(P2), until |ΔY| < 1e-9 (max 200).
Sizing: initial = smallest size with √(3647·ID^5.25·2000/100) ≥ Q (else 4"). Loop (≤ 500): compute; worst nozzle =
lowest pressure; if ≥ Pmin stop; else on the path B → worst choose the segment (size < 4") with the largest
startPsi − endPsi and upsize one step; none left → stop (check fails).
Orifice: area = q / nozzleFluxAt(P); code = smallest c in 1, 1.5, 2, … with π/4·(c/32)² ≥ area.
flowRows: one row per segment in traversal order (main first).

### Devices per enclosure
entry = point on the polygon boundary nearest the storage; u = unit(centroid − entry).
- detectors (smoke for 'smoke-cross-zoned', heat for 'heat', none for 'none-manual'): grid as nozzles with the detector
  spacing; zones alternate A, B; cross-zoned with a single detector → add one at +1000 mm x (inside, else −1000); tags SD-/HD-.
- horn-strobe at entry + 1000·u (inside); strobe-outside, manual-release, warning-sign at entry − 600·u (outside, spaced
  300 mm apart along the wall); a second warning-sign inside at entry + 1600·u; pressure-relief-vent at the boundary point
  farthest from the entry; selector-valve (when the floor has > 1 enclosure) near the storage (xb + 600, yb + 400k).
- Per floor (enclosureId null): control-panel, lockout-valve, pressure-switch, warning-sign near the storage. Unique tags.

### Checks (ids `co2-<name>:<floorId>/<encId>`)
occupancy (normally-occupied → fail "not permitted, use NFPA 2001 clean agent"), nozzle-pressure (min ≥ Pmin),
discharge (surface t ≤ 1 min; deep t ≤ 7 and rate ≥ W30/2), openings (surface: pass "compensated"; deep with
openings > 0 → warn), ventilation (0 → pass; surface → warn compensated / shutdown preferred; deep → fail must shut down),
time-delay (normally-occupied/occupiable/normally-unoccupied: ≥ 20 s pass else fail), orifice-ratio (orifice area /
supplying-pipe internal area within 0.10–0.70 → pass else warn), height (> 6 m → warn add nozzle tiers per listing).
System: co2-reserve (enclosures > 1 and no reserve → warn, else pass), co2-odorizer (odorizer false → warn), co2-detection
('none-manual' → warn).

### Storage
governing = enclosure with largest total; mainLb = its total; reserveLb = reserve ? mainLb : 0. HP: mainCylinders =
max enclosure cylinders; reserveCylinders = reserve ? main : 0; installed = (main + reserve) cyl × cylinderLb; tankTons null.
LP: tank = smallest of [1, 2, 3, 4, 6, 8, 10, 15, 20, 30] US tons ≥ (main + reserve)/2000; installed = tons·2000; cylinders 0.
