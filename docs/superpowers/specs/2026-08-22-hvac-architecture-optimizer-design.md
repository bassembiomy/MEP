# HVAC Architecture & Selection Algorithm Specification for Optimizer Studio

## 1. Overview
This specification details the architecture, component schemas, and 7-step engineering selection algorithm implementation for all 6 core HVAC system types in the Deterministic MEP HVAC Designer Optimizer Studio:
1. **Concealed Ducted Split Unit** (`concealed`)
2. **Cassette Split Unit** (`cassette`)
3. **High-Wall DX Split Unit** (`high-wall`)
4. **Variable Refrigerant Flow (VRF)** (`vrf`)
5. **Packaged Rooftop Unit (RTU)** (`packaged`)
6. **Central Air Handling Unit (AHU) / Chilled Water** (`ahu`)

Every system candidate evaluated within the Optimizer Studio will dynamically generate an itemized **Bill of Components** and a transparent, step-by-step **Selection Algorithm Trace** matching professional MEP engineering design standards (ASHRAE Fundamentals, ASHRAE 62.1/90.1, SMACNA).

## 2. Component Hierarchy & Bill of Materials Data Model

### 2.1 Component Categories
Each HVAC system type decomposes into five distinct MEP subsystem categories:
1. **Primary Equipment (`primary-equipment`)**:
   - Outdoor Unit (ODU) / Condensing Unit / Air-Cooled Chiller / RTU casing.
   - Indoor Fan Coil Unit (IDU) / Concealed Evaporator / Modular AHU.
   - Compressor type (Variable Speed Inverter, Twin Rotary, Scroll), Fans (EC/Direct Drive), Expansion Valves (EEV/TXV).
2. **Air Distribution & Ductwork (`air-distribution`)**:
   - Main supply duct trunk, branch takeoffs with 45° conical boots, rectangular/round transitions.
   - Flexible runout ducts, dynamic motorized fire dampers, manual volume dampers, acoustic sound attenuators/silencers.
3. **Air Terminal Devices (`terminals`)**:
   - Supply air diffusers (4-way square ceiling, linear slot, swirl, sidewall grilles).
   - Return air grilles (eggcrate, perforated, linear), exhaust/relief registers.
4. **Hydronics & Refrigerant Circuits (`hydronics-refrigerant`)**:
   - Refrigerant lineset (insulated copper suction/gas and liquid lines) or Chilled Water supply/return piping.
   - VRF Branch Selector (BS) boxes, Refnet distribution joints, 2-way/3-way modulating control valves, balancing valves, condensate drain line and P-trap.
5. **Controls & Electrical (`controls-electrical`)**:
   - Microprocessor digital thermostat / BACnet MS/TP zone DDC controller.
   - Variable Frequency Drive (VFD), VAV box airflow velocity sensors & actuators, electrical disconnect switch, and Full Load Amperage (FLA) rating.

## 3. Professional 7-Step Selection Algorithm Trace

### 3.1 Step-by-Step Decision Pathway
Each candidate generated by `generateSystemCandidates` executes and logs the 7 deterministic engineering stages:

1. **Step 1: Thermal Load & Sensible Heat Ratio (SHR)**:
   - Evaluates design Sensible Load ($Q_{sens}$) and Total Load ($Q_{tot}$).
   - Computes Sensible Heat Ratio $SHR = \frac{Q_{sens}}{Q_{tot}}$.
   - Establishes design room Delta-T $\Delta T = T_{room\_db} - T_{supply\_db}$ (default $20^\circ\text{F}$).
   - Pass Criteria: $0.65 \le SHR \le 0.95$.

2. **Step 2: Required Airflow Sizing (CFM) & ASHRAE 62.1 Fresh Air**:
   - Formula: $\text{CFM}_{thermal} = \frac{Q_{sens}}{1.08 \times \Delta T}$.
   - Fresh air breathing zone ventilation: $V_{bz} = R_p \times P_z + R_a \times A_z$ per ASHRAE 62.1.
   - Pass Criteria: $300 \le \frac{\text{CFM}}{\text{Tons}} \le 500\text{ CFM/ton}$.

3. **Step 3: Equipment Capacity & Ambient De-rating**:
   - Applies temperature de-rating factor $F_{amb}$ based on design outdoor dry-bulb (e.g. $95^\circ\text{F} - 115^\circ\text{F}$).
   - Derated Total Capacity: $Q_{derated} = Q_{nominal} \times F_{amb} \times F_{piping}$.
   - Quantity determination: $N = \lceil \frac{Q_{load}}{Q_{derated}} \rceil$.
   - Pass Criteria: Oversizing ratio between $0.98$ and $1.25$.

4. **Step 4: Air Distribution & Terminal Throw/Noise Criterion (NC)**:
   - Terminal count: $N_{diffusers} = \lceil \frac{\text{CFM}_{total}}{\text{CFM}_{rated/terminal}} \rceil$.
   - Neck velocity verification ($V_{neck} \le 600\text{ FPM}$ for quiet / $800\text{ FPM}$ general).
   - Diffuser throw verification: $0.75 \times L_{zone} \le T_{50} \le 1.25 \times L_{zone}$.
   - Room Noise Criterion check: $\text{NC}_{actual} \le \text{NC}_{space\_limit}$.

5. **Step 5: Aerodynamic Duct Sizing & Critical Path Static Pressure (ESP)**:
   - Sizing velocity per SMACNA ($1000 - 1200\text{ FPM}$ in main trunk, $700 - 900\text{ FPM}$ in branches).
   - Equal friction rate: $0.08 - 0.10\text{ in.wg per 100 ft}$.
   - Total external static pressure summation:
     $$\text{ESP}_{required} = \left(\sum \Delta P_{duct} + \sum \Delta P_{fittings} + \Delta P_{diffuser} + \Delta P_{filter} + \Delta P_{damper}\right) \times 1.15$$

6. **Step 6: Fan Operating Curve & Power Sizing**:
   - Maps $\text{ESP}_{required}$ onto equipment fan static capability curve.
   - Evaluates fan margin: $\text{ESP}_{available} - \text{ESP}_{required} \ge 0$.
   - Estimates fan electrical power & Brake Horsepower (BHP):
     $$\text{BHP} = \frac{\text{CFM} \times \text{ESP}}{6356 \times \eta_{fan}}$$

7. **Step 7: Piping, Circuiting, Diversity & Controls Strategy**:
   - Refrigerant suction/liquid pipe sizing or hydronic GPM flow sizing ($GPM = \frac{24 \times \text{Tons}}{\Delta T_{water}}$).
   - Maximum allowable equivalent length and lift limitations for DX/VRF linesets.
   - Thermostat / DDC / BMS integration strategy.

## 4. User Interface Enhancements in Optimizer Studio

### 4.1 Candidate Card Interactive Tabs
Each candidate card in `OptimizerStudioPanel.tsx` is enhanced with a 3-tab segmented control:
1. **Overview & Specs**: Key metrics (Capacity, CFM, Sound NC, ESP, Efficiency, Cost Index, and Diagnostics).
2. **Bill of Components**: Grouped by subsystem (*Primary Equipment*, *Air Distribution*, *Terminals*, *Piping*, *Controls*) showing tags, quantities, connection sizes, and specifications.
3. **Selection Algorithm**: Interactive accordion of the 7 engineering steps showing exact inputs, mathematical formulas, intermediate numbers, and green/amber compliance badges.

### 4.2 Interactive System Architecture Inspector Modal
Accessible via a button on candidate cards or the studio header:
- **System Schematic Diagram**: Visual flow diagram illustrating the equipment, ductwork, terminal devices, and piping loop for the selected system type.
- **Governing MEP Codes & Standards Reference**: Explicit notes on ASHRAE 90.1, ASHRAE 62.1, SMACNA, and AHRI ratings.
- **Bill of Materials Export / View**: Clear table ready for engineering schedules and submittals.
